# huggingface/inference-endpoint (Huggingface Inference Endpoint)

You can run this example with:

```bash
npx artef@latest init --example huggingface/inference-endpoint
cd huggingface/inference-endpoint
```

## Usage

To get started, set your HF_API_TOKEN environment variable. See also https://artef.dev/docs/providers/huggingface/ for setup details.

Next, edit artefconfig.yaml.

Then run:

```bash
artef eval
```

Afterwards, you can view the results by running `artef view`
