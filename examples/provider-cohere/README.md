# provider-cohere (Cohere)

You can run this example with:

```bash
npx artef@latest init --example provider-cohere
cd provider-cohere
```

## Usage

To get started, set your COHERE_API_KEY environment variable.

Next, edit artefconfig.yaml.

Then run:

```bash
artef eval
```

Or

```bash
artef eval -c complex_config.yaml
```

Afterwards, you can view the results by running `artef view`
