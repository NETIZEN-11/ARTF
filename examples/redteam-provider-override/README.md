# redteam-provider-override (Redteam Provider Override)

You can run this example with:

```bash
npx artef@latest init --example redteam-provider-override
cd redteam-provider-override
```

## Usage

This example shows how to use a custom provider for red team attack generation.

```bash
artef redteam generate
```

Then

```bash
artef redteam eval
```
