# openai-chat-history (Openai Chat History)

You can run this example with:

```bash
npx artef@latest init --example openai-chat-history
cd openai-chat-history
```

## Usage

To get started, set your OPENAI_API_KEY environment variable.

Next, have a look at prompt.json and edit artefconfig.yaml.

Then run:

```bash
artef eval
```

Afterwards, you can view the results by running `artef view`
