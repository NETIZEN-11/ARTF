# provider-replicate/lifeboat (Replicate Lifeboat)

You can run this example with:

```bash
npx artef@latest init --example provider-replicate/lifeboat
cd provider-replicate/lifeboat
```

## Usage

To get started, set your OpenAI and Replicate API tokens in artefconfig.yaml.

Then, add your test cases.

Then run:

```bash
artef eval
```

Afterwards, you can view the results by running `artef view`
